# Лабораторная работа: Расчет значений по формулам

## Автор
Ли Даниил (Вариант 3)

## Цель
Освоение базового синтаксиса C++ и математических вычислений на примере расчета значений по формулам.

## Описание
Программа вычисляет значения по 5 формулам.

## Исходные данные
- Под каким углом к горизонту брошено тело: 14 градусов
- Начальная скорость: 750 м/с
- Ускорение свободного падения: 9.81 м/с²
- Число пи: 3.14

## Ожидаемые результаты
Программа выводит пять значений:

- timeFly: время полёта по формуле (1)
- maxHeight: максимальная высота полёта по формуле (2)
- maxRange: максимальная дальность полёта по формуле (3)
- startCurvatureRadius: радиус кривизны начала траектории по формуле (4)
- apexCurvatureRadius: радиус кривизны вершины траектории по формуле (5)
